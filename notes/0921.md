.text: 実行する命令。 boot.o(.text)は明示的にboot.oを.textの先頭に配置する。
.rodata: 文字列などの読み取り専用データ。
.data: 初期値のある変数。
.bss : セロ初期化する変数など。
.は「現在の配置位置」

```ld 
ENTRY(_start)

SECTIONS
{
  . = 0x80000000;

  .text : {
    boot.o(.text)
    *(.text .text.*)
  }

  .rodat : {
    *(.rodat .rodat.*)
  }

  .data : {
    *(.data .data.*)
    *(.sdata .sdata.*)
  }

  .bss : {
    *(.bss .bss.*)
    *(.sbss .sbss.*)
  }
}
```

kernel.cppをRISC-v用の機械語に変換し、kernel.oを作成

```sh 
clang++ --target=riscv64-unknown-elf \
  -march=rv64imac -mabi=lp64 \
  -ffreestanding -fno-exceptions -fno-rtti \
  -mcmodel=medany \
  -c kernel.cpp -o kernel.o
```

-ffreestanding: OSが提供する実行環境を前提にしない。
-fno-exceptions -fno-rtti : C++の例外処理と実行時の型情報を無効にする。
-mcmodel=medany: 今回の配属先0x80000000に対応できるアドレスの扱いを指定
-c : 部品の作成までで、結合はしない

特定のアドレスへの読み書きで機器を操作する仕組みをMMIOと呼ぶ

```c++ 
// Use C Linkage so the assembly code can call kernel_main without C++ name
// mangling.
extern "C" void kernel_main() {
  volatile unsigned char *uart =
      reinterpret_cast<volatile unsigned char *>(0x10000000);

  *uart = 'A';
  for (;;) {
  }
}
```
- reinterpret_cast : 0x10000000をアクセス用のポインタとして使用
- volatile : この機器への書き込みを、コンパイラが不要と判断して消さないようにする。
- *uart = 'A' : UARTに文字を送る。

```c++
void uart_puts(char c) {
  volatile unsigned char *uart =
      reinterpret_cast<volatile unsigned char *>(0x10000000);

  // Wait until ready.
  while ((uart[5] & 0x20) == 0) {
  }

  uart[0] = c;
}
```

uart\[5\] & 0x20は状態の中から「次の文字をかけるか」を示すビットだけを取り出す。
また、0の間は処理を待ちつづける
UARTの送信用レジスタが1バイト単位のため、それに合わせてポインタを宣言。

トラップ処理
トラップは、CPUや例外や割り込みを受けて、専用の処理へ移る仕組み

例外ハンドラ
例外を受け取る処理
例外が起きたときにメッセージを表示して止まる関数を用意。

mvtec 
トラップ処理の入り口アドレスを保持する専用レジスタ。
これにアセンブリ側の入り口を登録すると例外が起きたら指定した関数へ進ませることができる。

-march=rv64imac_zicsrに変更
分解すると以下になる
rv64  = 64-bit RISC-V
i     = 基本整数命令
m     = 乗算・除算
a     = atomic命令
c     = compressed命令
zicsr = CSRアクセス命令
CSRはCPUの状態や制御に使用する特殊なレジスタ
以下を触るときによく使用する
mtvec    trap handlerの場所
mepc     trap発生時のPC
mcause   trapの原因
mstatus  CPUの状態

atmic命令
途中で他のCPUに割り込まれずに、メモリの読み書きをひとまとまりで行う命令
　マルチコアの場合にメモリ競合を防ぐための仕組み
compressed命令
RISC-V命令は基本的に32bitで呼び出されるが、この命令を使用すると16bitで表現できるようになる
プログラムのコードを短く圧縮できるので組み込みなどでよく使われる。

```asm
# Set the stack pointer to the top of the stack.
_start:
    la sp, stack_top

    # Set the trap entry.
    la t0, trap_entry
    csrw mtvec, t0
# Call the kernel_main
    call kernel_main

halt:
    j halt

.balign 4
trap_entry:
    call trap_handler
    j halt
```
- t0 : アドレスを一時的に入れるレジスタ
- csrw mtvec, t0 : t0の値をmtvecに書き込む。
- .balign 4 : 入り口を4バイト境界に揃える。mtvecの要件。

asm volatile("ebreak");
  asm volatileはC++の中に実行させたいアセンブリ命令を書く。
　ebreakは、意図的にブレークポイント例外を起こす命令。

```c++
  asm volatile("csrr %0, mcause" :
  "=r"(cause));

```
単純にmcauseを読み込んでt0に入れるという理解で問題ない
  - csrr：CPU の制御用レジスタを読む命令です。

  - %0：コンパイラが選ぶ出力先レジスタの場所です。

  - "=r"(cause)：そのレジスタに出した値を、C++ の変数 cause で受け取ります。

  - unsigned long：今回の64ビット環境では、mcause 全体を入れられる64ビットの整数型です。

```c++
void uart_put_hex(unsigned long value) {
  const char *digits = "0123456789abcdef";

  uart_puts("0x");

  for (int shift = 60; shift >= 0; shift -= 4) {
    uart_putc(digits[(value >> shift) & 0xf]);
  }
}
```
- value >> shift : 表示したい桁を右端へ移動
- & 0xf : 右端の4bitだけを取り出す
- digits[...] : その値を'0'~'f'の文字に変換する。
